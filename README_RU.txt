РОМАНТИЧЕСКИЙ САЙТ — ПРОСТАЯ ИНСТРУКЦИЯ

ВНУТРИ УЖЕ ЕСТЬ ГОТОВЫЙ САЙТ. Осталось добавить фото, подключить Telegram и опубликовать проект.

1) ФОТОГРАФИЯ
Положи фотографию девушки в папку public/images и назови её girl.jpg.
Если фотография в PNG или WebP, конвертируй её в JPG, не просто меняй расширение.
Если фото не добавлять, рамка с фото автоматически скроется.

2) TELEGRAM
- В Telegram найди @BotFather.
- Отправь /newbot и следуй инструкциям.
- Сохрани токен, который выдаст BotFather. Никому его не отправляй.
- Открой своего нового бота и нажми Start.
- Чтобы узнать chat ID, открой в браузере:
  https://api.telegram.org/botТОКЕН/getUpdates
  Вместо ТОКЕН вставь свой токен. Найди message -> chat -> id.
- Если getUpdates показывает пустой список, отправь боту сообщение ещё раз и обнови страницу.
- НЕ публикуй ссылку с токеном и не вставляй токен в HTML.

3) ПУБЛИКАЦИЯ (Render)
- Создай аккаунт на https://github.com/ и https://render.com/
- Создай новый репозиторий GitHub. Загрузи в него файлы и папки проекта, включая public/images/girl.jpg.
- Важно: не загружай файл .env. В этом проекте секреты нужно задавать через настройки Render.
- В Render выбери New + -> Web Service и подключи репозиторий GitHub.
- Build Command: npm install
- Start Command: npm start
- В Environment добавь:
  BOT_TOKEN = токен от BotFather
  CHAT_ID = твой chat ID
- Нажми Deploy. После успешного запуска Render покажет публичный адрес вида https://имя-сервиса.onrender.com.
- Открой этот адрес на телефоне и проверь страницу.

4) ПРОВЕРКА TELEGRAM
Открой публичный сайт, заполни форму тестовыми данными и отправь.
Ответ должен прийти в личный чат с твоим ботом.
Если не пришёл, проверь BOT_TOKEN и CHAT_ID в Render.

ПОЛЕЗНО ЗНАТЬ
- Ссылка работает, пока сервис опубликован и доступен.
- На бесплатном тарифе хостинга сервис может засыпать, поэтому первая отправка после паузы иногда занимает время.
- Не публикуй секретный токен. Если он утёк, отзови его через @BotFather.
- Используй фотографию, которой ты вправе делиться.
